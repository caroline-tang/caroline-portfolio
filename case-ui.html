Case 02 · UI

UI / Web 案例

以下两个产品端界面项目，每个项目下可放多张展示图；张数可按需增减。

跳转： 建业+ 中原足球

建业+ APP

建业集团旗下综合服务客户端，覆盖业主服务、社区与商城等场景。

职责
界面与组件规范、关键流程高保真、与开发标注对接。
范围
首页与核心服务动线、会员卡券与订单、消息与个人中心等模块。
结果
在保证品牌一致性的前提下提升信息层级与可用性，支持版本迭代交付。

中原足球 APP（原建业足球）

俱乐部官方应用，面向球迷的赛事、票务、内容与会员服务。

职责
赛事与数据展示、购票/会员动线、活动与内容板块的界面与状态设计。
范围
赛程比分、球队动态、个人中心与权益等主轴流程。
结果
适配赛季运营节奏的输出节奏，与产品、开发协作落地多版本。
